## 0. 为什么有两个博客文件

| 文件 | 用途 |
| --- | --- |
| `blog/博客-通讯录.md` | 仓库内归档版，用相对路径引用本地素材，供 GitHub / 本地阅读 |
| `blog/CSDN-发布版.md` | **本次要发的版本**，专为 CSDN Markdown 编辑器改写 |
| `blog/CSDN-预览.html` | 本地预览页，浏览器直接打开即可看到发布后的排版与 8 张图片（不用于发布） |

CSDN 版做了 5 处适配，直接粘原版会出问题：

1. **8 张图片全部换成 jsDelivr 公网 CDN 链接**（`cdn.jsdelivr.net/gh/...`），不再用 `../assets/`，粘贴后即可显示；
2. **`mermaid` 流程图换成 `assets/architecture.png` 架构图** —— CSDN 不渲染 mermaid，原版会显示成一坨代码；
3. **手写目录换成 `@[TOC](目录)`** —— 这是 CSDN 专属的自动目录语法；原版那些 `#锚点` 在 CSDN 上点不动；
4. **所有 `../docs/...` 相对链接换成 GitHub 绝对地址**，代码规范、示例 xlsx、视频、发布记录都能点开；
5. **删掉 `YOUR_VIDEO_URL` 占位符和所有「发布前请替换」的作者备注**，改为 GitHub 上可直接预览的 `demo.mp4` 链接。

正文无占位符、无本地路径、无内嵌视频标签，可直接发布。

> 按本人要求，正文**不含评分对照章节**（已整节移除），现为 11 章 + 附录参考资料。
> 作业清单里的 “Check against the grading rubric” 是学生自行核对，不必写进博客，删除不影响评分。

## 2. 发布步骤

1. 打开 [CSDN 创作中心](https://mp.csdn.net/) → **写博客** → 右上角切换到 **Markdown 编辑器**；
2. 填好上表的标题、摘要、标签、分类、封面；
3. 打开 [`CSDN-发布版.md`](CSDN-发布版.md)，**全选复制正文**粘贴到编辑器
   （也可用编辑器的「导入 Markdown 文件」直接选这个 `.md`）；
4. 检查 4 件事：
   - **目录**：`@[TOC](目录)` 应渲染成可点击的章节目录；若没有，见第 5 节排查；
   - **图片**：正文 8 张图应正常显示；若裂图，见第 4 节；
   - **表格**：作业描述表、功能清单表、PSP 表、贡献度表都能正常渲染；
   - **代码块**：`json / js / css / bash` 四段代码高亮正常，没有残留 `mermaid` 代码块；
5. 预览全文 → 点「发布博客」→ 选「原创 / 全部可见」→ 确认；
6. 等审核通过后，把**文章链接**填到作业系统（个人项目只需提交这一篇）。

## 5. 常见问题排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 目录没生成，只看到一行 `@[TOC](目录)` | 确认用的是 **Markdown 编辑器**（富文本模式不认这个语法）；仍不行就删掉该行，手工把 11 个章节标题列成目录 |
| 图片裂开 / 显示外链禁止 | 走第 3 节：点「一键转存」或逐张上传；也可把 CDN 前缀换成 `https://raw.githubusercontent.com/xie-yu520/contacts-address-book/main/assets/`（同一文件名） |
| 表格变成一坨文字 | CSDN 表格前后需要空行，确认粘贴时没有丢空行；必要时在编辑器里用「插入表格」重建 |
| 代码块没有高亮 | 确认语言标记是 ```json / ```js / ```css / ```bash，且反引号成对 |
| 目录里出现「目录」这一项 | 正常，`## 目录` 本身是 H2；想去掉就把 `## 目录` 那行删掉，只留 `@[TOC](目录)` |
| 文章一直「审核中」 | CSDN 新文/含外链的文章可能需要人工审核，这正是要**提前一天发**的原因 |
